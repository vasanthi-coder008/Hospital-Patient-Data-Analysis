# Hospital-Patient-Data-Analysis
Hospital Patient Data Analysis and Decision Support System using Python, Pandas, and NumPy for data cleaning, risk analysis, and visualization.
## Abstract
This project uses Python to clean and analyze hospital patient data and summarize patient risk levels and triage patterns.

## Objectives
- Identify and handle missing values.
- Remove duplicate records.
- Analyze patient risk categories.
- Visualize triage-level distributions.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Implementation
1. Load the dataset.
2. Inspect missing values and duplicate rows.
3. Clean the dataset.
4. Analyze risk and triage categories.
5. Generate visualizations and export the cleaned data.

## How to Run
Open the Jupyter Notebook in Google Colab and upload the required dataset when prompted.
